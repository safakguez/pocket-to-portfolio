# Pocket to Portfolio – Website

Öffentliche Seite des Spiels „Pocket to Portfolio“ (GitHub Pages): Startseite, Datenschutzerklärung
(Deutsch + Englisch) und Impressum. Der Link `…/privacy.html` bzw. `…/datenschutz.html` wird in der
Google Play Console als Datenschutzerklärung eingetragen.

- Reines HTML/CSS, keine Cookies, keine externen Schriften, kein Tracking.
- Der Code des Spiels liegt im privaten Repo `cash-climb`.
- Ändert sich die App (z. B. Werbung, Käufe, neue Dienste), die Datenschutzerklärung in **beiden**
  Sprachen anpassen und das Datum „Stand“ aktualisieren.
